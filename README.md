# CIS 4394 · Agentic AI · Spring 2026 — Student Showcase

A showcase and text analysis of all 86 student agentic-AI projects, built from the
full text of 201 Milestone I and Milestone II submissions.

- `index.html` — the showcase site
- `files/` — original student submissions (PDF/DOCX), linked from each project card
- `v1-index.html` — earlier version of the showcase (March 2026)

The site is served with `noindex` / `nofollow` meta tags and a `robots.txt` that
disallows all crawlers, so it does not appear in search results. Share the link
directly with the class.
